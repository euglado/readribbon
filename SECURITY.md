# Security / Güvenlik

English: Report vulnerabilities privately through this repository's GitHub Security → Report a vulnerability option **if enabled**. If unavailable, use an existing private contact method with the repository owner; no dedicated security mailbox or response SLA is provided. Do not publish exploit details, tokens, `.env`, source text or raw requests in a public issue. Rotate exposed tokens immediately in the Developer Portal. Include affected version, impact and synthetic reproduction steps. This is a small self-hosted project without a security certification. Source-pattern scanning and npm audit are limited automated checks, not proof of absence of vulnerabilities.

Türkçe: Etkinse GitHub Security → Report a vulnerability üzerinden özel bildirim yapın. Seçenek yoksa depo sahibiyle mevcut özel iletişim yolunu kullanın; özel güvenlik e-posta adresi veya yanıt süresi taahhüdü yoktur. Açık issue içine saldırı ayrıntısı, token, `.env`, kaynak metin veya ham istek eklemeyin. Sızan tokenı Developer Portal'da hemen yenileyin. Etkilenen sürüm, etki ve yapay yeniden üretme adımlarını iletin. Proje kendi hostunuzda çalışır; güvenlik sertifikası yoktur. Desen taraması ve npm audit sınırlı otomatik kontrollerdir, açık bulunmadığının kanıtı değildir.

Only the current main version receives fixes / Yalnızca güncel main sürümüne düzeltme uygulanır.
